# 10_tech_stack.md

## 1. 実行環境
- **OS**: Linux
- **権限**: `sudo` を必要とする操作は行わず、ユーザーに指示を求めること。

## 2. 基本ディレクトリ構造
- **.ai-rules/**: AI 共通ルール（SSOT）の実体。
- **.githooks/**: Git Hook による物理制約（改行・秘匿情報等）。
- **.github/workflows/**: CI による自動検証（PRバリデーター、gitleaks）。
- **pkg/**: プロジェクト固有のビジネスロジック。
- **frontend/**: フロントエンド資産（存在する場合）。

## 3. ファイル管理
- **README.md**: プロジェクトの設計思想と構造図を管理。構成変更時は自律的に更新せよ。
- **.editorconfig**: インデント、改行等のエディタ設定。これに従いファイルを生成せよ。
- **秘匿情報**: `.env` や Secret Manager を利用し、追跡対象ファイルに含めないこと。
