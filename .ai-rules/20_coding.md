# 20_coding.md

## 1. 物理ファイル制約
- **文字コード**: UTF-8（BOMなし）を厳守せよ。
- **改行コード**: LF（Unix形式）のみを許可する。CRLFは厳禁。
- **末尾改行**: すべてのファイルの最終行には必ず改行（LF）を入れよ。

## 2. セキュリティ（秘匿情報ガード）
- **リテラル記述禁止**: `api_key`, `password`, `token` 等の変数に対し、文字列リテラルを直接代入することを厳禁とする。
- **CI/CD設定**: `.github/workflows/` 内では必ず `${{ secrets.* }}` または `${{ vars.* }}` を使用し、値を直書きしてはならない。
- **環境情報**: `/home/user` 等の絶対パスや `192.168.x.x` 等のプライベートIPをコード内に混入させるな。

## 3. コーディングスタイル
- **最小差分主義**: 冗長な書き換えを避け、ロジック変更に不可欠な箇所のみを修正せよ。
- **未使用コード**: 未使用の `import` や変数は、修正のついでに自律的に削除せよ（事後報告必須）。
- **言語設定**: 対話、ソースコード内のコメント、およびドキュメントは日本語を基本とする。
